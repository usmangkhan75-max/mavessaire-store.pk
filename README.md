# MAVESSAIRE — Inspired fragrances

Responsive storefront for the Pakistan market. Built as a static site for GitHub Pages.

## Live website
https://usmangkhan75-max.github.io/mavessaire-store.pk/

## Included
- Responsive MAVESSAIRE storefront in a light-blue / white palette
- Sample inspired fragrance collection with category filters
- Shopping bag and demo checkout
- Rs. 250 flat delivery fee
- Cash on Delivery and bank transfer options
- Scent finder recommendations

## Important
This is a front-end demo. Orders are saved only in the visitor's browser localStorage and are not sent to the business. Do not use this demo to accept real customer orders or payments. Before launch, connect a secure backend/database, admin authentication, order notifications, stock management, privacy/terms pages and a real payment/order workflow.

GitHub Pages hosts static files only. Live AI chat, WhatsApp notifications, abandoned-cart recovery, shared inventory and server-side order management require a separately hosted backend and connected provider accounts. Never put API keys in frontend code.

## Deployment
The GitHub Actions workflow deploys the root site to GitHub Pages whenever code is pushed to main. In repository Settings → Pages, select GitHub Actions as the build and deployment source if it is not already selected.
